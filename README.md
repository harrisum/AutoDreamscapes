# Steno's Auto Dreamscapes Solver

Here's my cute little applet for Dreamscapes enthusiasts who want to guarantee 32,100+

Two modes:

- Teach: Ctrl-Alt-T to enter this mode (must press to teach for EACH item); click on the item's label in the center of the box, then click on the item in the scenary.
- Solve: Ctrl-Alt-S to enter this mode; solve!
- Stop: Ctrl-Alt-X to cancel a mode. You can also click with your mouse to stop Solve.

## To begin

1. Extract the Windows build, open `AutoDS.exe`
2. Set your preferred MS and pixel location jitter (recommended for 32k: 65-85, 2 pixels)
3. Train the tool using teach mode (Ctrl-Alt-T)
4. You're done! Use Solve mode to get the score your heart desires.

## Note

You have to train it yourself, and since the scene resets every day, there isn't much interface for saving, exporting, etc. If that's something people would like to see, let me know.
